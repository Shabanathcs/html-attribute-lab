Elements and attributes

Parts of an HTML element

Tap a part name to light it up in the code.

An element is the start tag, the content and the end tag together.

Element
Start tag + content + end tag. It tells the browser what something is: a heading, a paragraph, a line break.
<p>Hello</p>
Attribute
Extra information about the element. It is written inside the start tag as name="value".
<p name="value">
The style attribute
Changes how an element looks. Inside the quotes we write property:value; with a colon and a semicolon.
style="property:value;"

Fire drill at 10:00 am

Remember the 4 golden rules

  1. Write the attribute inside the start tag, never in the end tag.
  2. Put the value inside double quotes: style="..."
  3. Use a colon between property and value: color:Tomato
  4. Spell it the American way: color, not colour. Use a hyphen in background-color.

Two properties in one tag? Separate them with a semicolon: style="color:white; background-color:red;"
